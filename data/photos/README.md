# Your own photos for the Living Waters homepage backdrop

The homepage rotator has 6 slots reserved for your own local photos, alongside
the sourced Wikimedia ones. Until a file exists, that slot shows an on-brand
placeholder instead of a broken image — so nothing looks off in the meantime.

To fill a slot, just save your photo into this folder with this **exact** name:

| Filename          | Suggested subject (just a suggestion — use whatever you have) |
|--------------------|------------------------------------------------------------|
| `local-01.jpg`     | A waterfall you've visited                                  |
| `local-02.jpg`     | Lake Chatuge from your favorite spot                        |
| `local-03.jpg`     | Sunrise or sunset over the mountains                        |
| `local-04.jpg`     | A trail, overlook, or gap view                              |
| `local-05.jpg`     | Any season — fall color, snow, spring green                 |
| `local-06.jpg`     | Whatever else you like                                      |

Notes:
- File format: `.jpg`. If what you have is `.png` or `.heic`, just tell me and I'll
  update the filenames it looks for, or convert it.
- Wide/landscape shots work best — this is a full-bleed background image behind
  glass panels, so a roughly 16:9 crop (or wider) avoids awkward cropping.
- No size limit that matters here, but if a phone photo is several MB that's fine —
  it only loads once per visit.
- Nothing else needs to change — the moment a file lands with the right name, the
  rotator picks it up automatically next time the page loads.
