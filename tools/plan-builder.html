Reading Plan Builder

Build a real reading plan for Commute Companion — any length, any meeting schedule. A 3-day study, a 4-week book study, a 6-month plan, or a full year like Bible in a Year. No fixed structure assumed.

Load an existing plan to edit
Loading a plan fills in the form below so you can edit and re-save it. Saving always writes to data/plans/<plan_id>.json — the same file the Commute Companion reads live.
1 · Plan details
"Daily" means one session per calendar day. "Specific days" (e.g. Tue/Thu for a 2x/week group) counts real meeting-day occurrences, not calendar days, when Commute Companion figures out which session you're on today.
2 · Sessions
3 · Import from a file
Upload a plain-text or CSV reading plan and this parses it into sessions using this server's AI connection (needs internet for this step). CSV columns, if present: session,title,readings,notes. Plain text works too — just make sure each session/day is clearly on its own line.
This adds parsed sessions to whatever's already in the form above — it won't erase sessions you've already entered. Review the result before saving; nothing is written to disk until you hit Save.
