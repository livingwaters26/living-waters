# Bible Commentary Project — Master Tracker

This is now a tracked initiative, not a someday-idea. Same system as the site redesign checklist:
a numbered list, status per item, and ready-to-paste prompts so it moves forward every time you
bring it up — nothing gets silently reprioritized behind other work again.

**Scale, stated plainly:** 66 books, 1,189 chapters. Revelation-depth commentary (structural
movement + key words + typology + teaching notes per chapter, not word-by-word annotation of
every verse) is realistic to produce for a full book in one focused session for shorter books,
and 2–3 sessions for the longest ones (Matthew, Luke, Acts, Psalms). This is a real multi-month
project either way — the plan below is how it actually gets finished instead of stalling again.

already done). On starting, user redirected the format: not the Movement/Key-words/Typology/

a plain "what it says / what it means" explanation, Greek/Hebrew word-notes where the original
language clarifies meaning, and tradition comparison — but **differences-only**: traditions that
agree get folded into one shared line, only genuine divergence gets its own box. Confirmed final
tradition list: **Catholic, Reformed/Calvinist, Lutheran, Baptist, Non-Denominational** (Armstrong/
VerseByVerseMinistry + Scofield) — Evangelical dropped from the older 6-tradition set.

**Delivery format confirmed: "both at once per book"** — content stays directly in the site's
`chNN.html` room pages as they're written (this project doesn't get a separate standalone
`.md` file the way Revelation's Bible Commentary Project did, since this IS the site page).

new standard — both passage cards (Genealogy 1:1-17, Virgin Birth Announced to Joseph 1:18-25)
rewritten from stubs to real content for Reformed and Lutheran (previously just "research online"


**Methodology refined three times over this session:**
1. **"What it means" must come from Scripture explaining Scripture, not outside commentary.** The base explanatory layer now cross-references other Bible passages directly (e.g., the genealogy's Davidic throne-right ties to 2 Samuel 7:12-16, the Abrahamic promise ties to Genesis 12:1-3/22:18) — a new "🔗 Scripture explaining Scripture" line, separate from the denominational layer.
2. **Denominational views must be grounded in real, verifiable commentators, not composed positions.** User explicitly wants real named commentaries (Spurgeon, Calvin, Luther, other Reformed figures, modern commentators too) actually searched and used, not plausible-sounding synthesis. Doing this caught a real error: initial draft claimed Calvin left Mary's perpetual virginity an open question — verified via search that this is **wrong**. Calvin, like Luther, actually affirmed perpetual virginity explicitly in his own commentary on this verse, calling the opposing reading "folly." The real historical divide is later: 19th-20th century Protestant scholarship and the Baptist/non-denom tradition broke from what Luther AND Calvin both originally held. Ch01 corrected to tell this more accurate, more interesting story. **Every future chapter needs this same verification step before tradition content ships — don't trust a plausible-sounding position without checking it.**
3. **A third layer — Early Church writings, historical writings, and Apocryphal material (Enoch named as an example) — presented as *other ideas that were in circulation on the subject*, explicitly not as Scripture-equal sources.** New `.extra-note` callout, clearly labeled "context, not Scripture" every time it appears. **Confirmed this applies broadly** — not just the NT Commentary Project, but Scripture Studies and Topical Studies generally (Millennial Kingdom, Messianic Prophecy, Parables, etc. — anywhere a real early-church or extra-biblical text bears on the passage/topic). Not forced into every passage — only where a genuine, verifiable connection exists. First real example, verified via search: Matthew 1:25's Virgin Birth passage now cites the *Protevangelium of James* (~2nd century AD) as the earliest surviving text explicitly asserting Mary's perpetual virginity — the likely historical origin point of the doctrine Luther and Calvin later inherited. Genesis 1-11/Jude/eschatology-heavy passages are where the Book of Enoch specifically will actually come up (1 Enoch is directly quoted in Jude 14-15) — not forced into Matthew 1, which has no real connection to it.

Same pattern as the site conversion checklist:
